Everything here lives in this one HTML file and travels over a WSS WebSocket. Anyone connected to the same room on the same relay sees your messages.

Open Settings to change the server, grab the relay that goes with this page, or get it onto a public URL.

Connection

Point the room at a WSS relay, pick a room name and say who you are.

This page is served over https, so the browser will block a ws:// address. Use wss://.
Need a server? Copy the relay

A browser can make WSS connections but it cannot accept them, so a room needs a relay. This is a tiny Node.js one with a single dependency (ws). Its address gets wss:// once it is behind TLS — Render, Fly, Railway or any reverse proxy will do that for you.

Run it locally with npm i ws then node server.js, and connect to ws://localhost:8080.


          

            
            
          

        

      


      

        Put it online (static host or cloudflared)
        

          
For a permanent address, put this one file on a static host that serves https — Cloudflare Pages, GitHub Pages, Netlify — and nothing has to stay running. For a temporary link from your own machine, node serve.js plus cloudflared tunnel --url http://localhost:8080 does it.

          
Either way the page is https, so the socket must be wss://. The relay itself still needs a host of its own; the guide lists free ones.
